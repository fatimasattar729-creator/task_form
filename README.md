Simple CRUD (HTML & CSS)

This project is a simple and clean CRUD (Create, Read, Update, Delete) user interface built using HTML and CSS.
It includes a form for entering data and a table for displaying records in a structured layout.

📌 Features

Input fields for:

First Name

Last Name

Email

Gender

City

Display table with full layout

Action buttons:

Edit

Delete

Clean UI with borders, spacing, and modern styling

Fully responsive layout structure

Built purely with HTML + CSS (no backend)

🔧 How It Works

User enters details in the form fields.

Data is shown in the table below (static for now).

The Edit and Delete buttons are styled placeholders for future functionality if backend is added.

This project is created to practice:

Form design

Styling with CSS

CRUD UI structure

Basic front-end organization
